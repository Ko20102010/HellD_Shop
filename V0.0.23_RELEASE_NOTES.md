# v0.0.23 - Four-squad idle RPG UI update

## Changed
- Expedition combat now deploys four active squad members with no spare slot.
- Normal encounters contain two or three enemies; elite encounters contain two enemies.
- Battle canvas now presents a compact 2D side-view formation with visible movement, attack traces, hit feedback, HP and skill-energy bars.
- Added five-button navigation: Home, Squad, Battle, Industry and Menu.
- The existing three-slot save manager is automatically opened at launch.
- Removed the player-facing 500KG control, arrow sequence, GitHub ZIP control, packager modal and JSZip dependency.
- Reduced persistent HUD clutter and added phone responsive rules.

## Save compatibility
- Existing application storage keys are unchanged.
- Combat snapshots migrate in memory from the old single `enemy` field to the new `enemies` array.
- Existing v0.0.22 progression should remain readable; active combat resumes through the compatibility path.
